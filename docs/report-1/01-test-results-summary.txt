FAILED TESTS (3)
----------------
All 3 failures are in ReadToTime and are environment/configuration issues,
not logic bugs:

1. ReadToTime.saveTest()
   Error: NullPointerException in ConnectionHandler.loadSavedData()
   Cause: DBType.ALL requires a valid save path for connections; the
          ConnectionHandler receives null for its table file name.

2. ReadToTime.readOnlyDB()
   Error: RuntimeException wrapping InvocationTargetException
   Cause: Partial table registration — only Author table is configured
          with LocalConfiguration, but Book table is not, causing a
          reflection error during table startup.

3. ReadToTime.exportTest()
   Error: NullPointerException in ConnectionHandler.loadSavedData()
   Cause: Same root cause as saveTest — DBType.EXPORT initializes
          connections that require file paths not provided in test config.
